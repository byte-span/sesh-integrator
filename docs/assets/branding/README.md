# sesh-integrator logos

Transparent PNG logo assets created for this project with OpenAI image generation.
All three contain black artwork for use on light backgrounds.

| Asset                                             | Dimensions | Use                                             |
| ------------------------------------------------- | ---------- | ----------------------------------------------- |
| [Full logo](sesh-integrator-logo-transparent.png) | 2172 × 724 | Symbol with the full `sesh-integrator` wordmark |
| [Compact logo](seshx-logo-transparent.png)        | 2172 × 724 | Symbol with the `seshx` command name            |
| [Symbol](sesh-integrator-symbol-transparent.png)  | 1774 × 887 | Standalone merging-path arrow                   |

Keep the transparent background and resize proportionally when reusing these
raster assets. The files preserve the original generated PNGs without changes.

The web dashboard header and favicon embed an SVG trace of the symbol; see
`logoPath` in `src/dashboard-web-assets.ts`.
